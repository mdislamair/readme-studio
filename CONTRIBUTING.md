# Contributing to README Studio

Thanks for helping improve README Studio.

## What we welcome

- Original GitHub profile README templates
- Improvements to accessibility, readability, or mobile rendering
- Fixed or updated links
- Clear usage instructions
- Documentation improvements

## Before submitting

1. Make sure the template is your own work or that you have permission to contribute it.
2. Use obvious placeholders such as `[Your Name]` and `yourusername`.
3. Avoid fake achievements, fake metrics, or claims that users might accidentally leave in place.
4. Test links and remove unnecessary external widgets.
5. Add the template to the gallery table in `README.md`.

## Pull request steps

1. Fork the repository.
2. Create a branch.
3. Commit your changes with a clear message.
4. Open a pull request explaining the change.
